# Question Framework Selection Rules

## Purpose

Use a structured question framework when it materially improves
decomposition of the user's research question and development of
search concepts.

Do not force a framework when the user's request is a simple
bibliographic, factual, or narrowly defined literature search.

Select one primary framework unless the user explicitly requests
another approach.

## Available frameworks

### PICO

Use primarily for intervention, treatment, effectiveness, or
comparative questions.

Components:

- P — Population / Problem
- I — Intervention
- C — Comparator
- O — Outcome

Typical questions:

- Does intervention X improve outcome Y?
- Is treatment X more effective than treatment Y?
- What is the effect of intervention X in population Y?

Do not invent a comparator when none is required.

---

### PECO

Use primarily for exposure, association, risk-factor, environmental,
etiological, or observational questions.

Components:

- P — Population
- E — Exposure
- C — Comparator
- O — Outcome

Typical questions:

- Is exposure X associated with outcome Y?
- Does risk factor X increase the risk of Y?
- What is the relationship between exposure X and outcome Y?

Do not convert an exposure into an intervention merely to fit PICO.

---

### PCC

Use primarily for scoping, mapping, exploratory, broad-concept,
or evidence-landscape questions.

Components:

- P — Population
- C — Concept
- C — Context

Typical questions:

- What evidence exists regarding concept X in population Y?
- How has topic X been studied in context Y?
- What are the characteristics of the literature on topic X?

PCC is especially appropriate when the objective is to map evidence
rather than estimate an intervention effect.

---

### PICo

Use primarily for qualitative questions involving experiences,
perceptions, meanings, attitudes, or phenomena.

Components:

- P — Population
- I — Phenomenon of Interest
- Co — Context

Typical questions:

- How do participants experience phenomenon X?
- What are the perceptions of population Y regarding X?
- How is phenomenon X understood within context Y?

Do not interpret the "I" in PICo as an intervention.

---

### SPIDER

Use when a qualitative or mixed-methods question requires more explicit
attention to study design or type.

Components:

- S — Sample
- PI — Phenomenon of Interest
- D — Design
- E — Evaluation
- R — Research type

Typical uses:

- qualitative evidence searches;
- mixed-methods evidence searches;
- questions where study design is an important eligibility element.

Prefer PICo when a simpler qualitative framework is sufficient.

---

### NONE

Use when a formal framework would add little value.

Examples:

- finding a known article;
- DOI verification;
- identifying papers by a specific author;
- simple topic searches with clearly defined concepts;
- bibliographic verification.

When NONE is selected, continue using the core-concept workflow in
SKILL.md.

## Framework selection rules

Select the framework based on the user's question, not merely on the
discipline.

Use the following decision logic:

1. Intervention or comparative effectiveness question → PICO
2. Exposure, association, risk, or etiological question → PECO
3. Broad mapping or scoping question → PCC
4. Experience, perception, or qualitative phenomenon → PICo
5. Qualitative/mixed-method question requiring design/evaluation
   specification → SPIDER
6. Simple bibliographic or focused concept search → NONE

If more than one framework appears possible, select the framework that
best represents the primary research objective and briefly explain the
choice.

Do not combine multiple frameworks unless there is a clear
methodological reason.

## Missing-element rule

Do not invent missing framework elements.

Examples:

- If a PICO question has no comparator, report:
  "Comparator: Not specified."
- If context is not defined in PICo, report:
  "Context: Not specified."

Missing elements should not prevent the literature search unless they
are essential to interpret the user's question.

## Search translation rule

Framework components guide concept development but do not require every
component to appear in the Boolean search string.

Avoid making the search unnecessarily restrictive.

For example:

- Comparator terms may be omitted from a PICO search.
- Outcome terms may be omitted when they substantially reduce
  sensitivity.
- Context terms may be omitted when they are not necessary to retrieve
  relevant evidence.

Clearly distinguish:

- framework elements;
- searchable concepts;
- terms actually used in the Boolean search.

## Framework integrity rule

The selected framework structures the question and search strategy.

It does not by itself determine:

- evidence status;
- article quality;
- inclusion or exclusion;
- DOI verification status.

All screening and verification decisions must continue to follow
SKILL.md and any relevant domain-specific reference rules.
